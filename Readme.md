LeetCode Profile Seeker

A simple web project that allows you to search for a LeetCode user and view their profile information in one place.

About the Project

I built this project to practice HTML, CSS, and JavaScript and to learn how to work with APIs.

You can enter a LeetCode username, and the website fetches the user's profile data and displays it in a simple dashboard.

Features
Search for a LeetCode username
Display user profile information
Show solved problems
Display Easy, Medium and Hard problems
Show contest rating and ranking
Simple and responsive UI
Dark-themed design
Technologies Used
HTML
CSS
JavaScript
LeetCode API
How It Works
Enter a LeetCode username.
Click on the search button.
JavaScript sends a request to the API.
The API returns the user's LeetCode information.
The information is displayed on the webpage.
